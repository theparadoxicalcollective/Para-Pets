# ParaPets Item Balance Guide

This guide is for **pet accessories and mini pets that grant ATK / DEF / HP**. Clearing equipment continues to use its existing slot-specific power weights and rarity budgets.

## Why the scale is conservative

A normal pet starts around 50 ATK, 50 DEF, and 1000 HP, while accessory bonuses stack across multiple equipped slots. ATK and DEF therefore receive full score weight and HP receives 0.05 score weight (20 HP ≈ 1 power).

## Price targets

| Coin price | Target power |
|---:|---:|
| 1–500 | 8–12 |
| 501–1,000 | 13–18 |
| 1,001–1,500 | 19–24 |
| 1,501–2,000 | 25–30 |
| 2,001–2,500 | 31–35 |
| 2,501–3,000 | 36–40 |
| 3,001–3,500 | 41–46 |
| 3,501–5,000 | 47–55 |
| 5,001+ | 56–65 |

Power score = `ATK + DEF + (HP × 0.05)`.

## Rarity targets

| Rarity | Target power |
|---:|---:|
| 1★ | 8–15 |
| 2★ | 16–25 |
| 3★ | 26–38 |
| 4★ | 39–50 |
| 5★ | 51–65 |

Price and rarity do not have to match perfectly. Limited cosmetics can cost more without having stronger stats; the goal is to prevent an expensive stat item from being dramatically weaker than normal and to prevent one purchase from invalidating progression.

## 3,500 coin staff set

These five builds intentionally have similar total power but different roles:

- Nature staff: +18 ATK / +18 DEF / +160 HP = 44 power
- Celestial staff: +32 ATK / +10 DEF / +80 HP = 46 power
- Mushroom staff: +8 ATK / +28 DEF / +180 HP = 45 power
- Eye staff: +38 ATK / +6 DEF / +40 HP = 46 power
- Aqua crystal staff: +22 ATK / +16 DEF / +140 HP = 45 power

## Rules for future items

Avoid giving a single accessory premium values in all three stats. Prefer one clear role (damage, tank, balanced, survivability) and use secondary stats to bring it into the target budget. Keep Clearing gear on its existing separate balance model because weapon/armor/boots/charm slots have different combat weights.
